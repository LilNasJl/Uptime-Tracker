How to Connect Any PC to This Website

Copy the single file cli/tracker.php to any PC you want to monitor.

Step 1: Set the PC Name & Website URL (One-Time Setup)

Run this command on the PC to save its custom name and your Hostinger URL into config.json:

php tracker.php setup --name="Office-PC-1" --api="https://yourdomain.com/api.php"

Step 2: Sync Past Boot/Shutdown Logs & Start Live Tracking

php tracker.php watch

This automatically syncs the PC's Windows Event Log (Turned ON/OFF history) and sends a live heartbeat every 60 seconds.

Step 3: Run Automatically When the PC Turns ON (Windows Task)

Or simply run this command once on that PC so it runs silently in the background on every boot:

php tracker.php install-startup
